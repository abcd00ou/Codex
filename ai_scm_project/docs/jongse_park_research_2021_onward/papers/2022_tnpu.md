# TNPU: Supporting Trusted Execution with Tree-less Integrity Protection for Neural Processing Unit

## Original English Notes

Venue: HPCA 2022  
Source: https://jongse-park.github.io/publications/

TNPU supports trusted execution for NPUs using tree-less integrity protection.

## 한글 번역 요약

TNPU는 NPU에서 trusted execution을 지원하기 위한 integrity protection 연구다. 보안 기능을 넣으면서도 accelerator 성능 overhead를 줄이는 것이 핵심이다.

## 박종세 교수 전문성 관점

박 교수님은 secure AI accelerator architecture를 꾸준히 연구해 왔다.

## 내 프로젝트 연결점

regulated enterprise AI, private inference, confidential computing 수요가 커질수록 security overhead가 capacity model에 들어갈 수 있다.
