# LPU: A Latency-optimized and Highly Scalable Processor for Large Language Model Inference

## Original English Notes

Venue: IEEE Micro 2024, Best Paper Award  
Source: https://jongse-park.github.io/files/paper/2024-ieee_micro-lpu.pdf

LPU is a latency-optimized processor for LLM inference from HyperAccel. It emphasizes memory bandwidth utilization, streamlined dataflow, scalable multi-device synchronization, and a software framework called HyperDex. The paper reports latency and energy-efficiency gains over GPU baselines for selected model sizes.

## 한글 번역 요약

LPU는 LLM inference를 위해 latency와 memory bandwidth utilization에 초점을 둔 processor다. LLM generation은 작은 vector input으로 큰 weight를 계속 읽는 memory-bound 특성이 있으므로, GPU보다 memory bandwidth를 효율적으로 쓰는 architecture가 중요하다고 본다.

## 박종세 교수 전문성 관점

박 교수님은 academic system research와 industry LLM accelerator product를 연결하는 위치에 있다. LPU 논문은 실제 AI semiconductor product와 research insight가 만나는 사례다.

## 내 프로젝트 연결점

purpose-built accelerator를 GPU 대비 몇 배 효율로 볼지 판단할 때 LPU가 중요한 reference다. 다만 model size, context length, batch pattern, software compatibility에 따라 uplift가 달라지므로 단순 fixed multiplier로 쓰면 위험하다.
