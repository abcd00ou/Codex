# General-Purpose Code Acceleration with Limited-Precision Analog Computation

## Original English Notes

Venue: ISCA 2023 Retrospective  
Source: https://jongse-park.github.io/publications/

This is a retrospective recognition of earlier work on limited-precision analog computation for general-purpose code acceleration.

## 한글 번역 요약

이 논문은 limited-precision analog computation을 general-purpose code acceleration에 적용한 과거 연구의 retrospective 선정이다. approximate/limited-precision computing의 긴 연구 흐름을 보여준다.

## 박종세 교수 전문성 관점

박 교수님은 AI accelerator 이전부터 approximate computing, precision trade-off, unconventional acceleration에 대한 깊은 연구 이력이 있다.

## 내 프로젝트 연결점

장기적으로 AI compute efficiency는 digital GPU scaling만이 아니라 approximate/analog/low-precision 방향에서도 개선될 수 있다. 2030년 이후 efficiency upside를 논의할 때 배경 reference가 된다.
