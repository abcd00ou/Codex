# Common Counters: Compressed Encryption Counters for Secure GPU Memory

## Original English Notes

Venue: HPCA 2021  
Source: https://jongse-park.github.io/publications/

Common Counters studies compressed encryption counters for secure GPU memory.

## 한글 번역 요약

이 논문은 secure GPU memory에서 encryption counter overhead를 줄이는 연구다. GPU memory security는 capacity, bandwidth, metadata overhead와 연결된다.

## 박종세 교수 전문성 관점

박 교수님은 GPU memory system과 security overhead를 함께 다루는 architecture 전문성을 갖고 있다.

## 내 프로젝트 연결점

confidential AI가 보편화되면 GPU memory security overhead가 HBM capacity와 bandwidth에 영향을 줄 수 있다. 현재 모델에는 없지만 enterprise AI scenario에서 고려할 수 있다.
